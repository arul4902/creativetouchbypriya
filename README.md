# Creative Touch by Priyaa — Luxury Bridal Makeup Website

Official production brand website for **Creative Touch by Priyaa**, a premier South Indian bridal makeup artist in Chennai specializing in *"Natural Glam"*.

- **Experience**: 7+ Years of Bridal Artistry

- **Instagram**: [@creative_touch_by_priyaa](https://www.instagram.com/creative_touch_by_priyaa)

## 🚀 Key Features

1. **Editorial Luxury Design**: Custom typography (`Cormorant Garamond` & `Plus Jakarta Sans`) with an elegant palette of Warm Ivory, Antique Gold, and Deep Espresso.
2. **Interactive Bridal Look Finder Quiz**: 3-step interactive selector calculating personalized look recommendations and building direct prefilled WhatsApp enquiries.
3. **The Art of Enhancement (Before ↔ After Dual Slider)**: Interactive touch- and pointer-enabled comparison slider highlighting real skin elevated with Natural Glam.
4. **Real Brides Portfolio**: Filterable gallery featuring Priyaa's genuine South Indian Muhurtham, Reception, and Engagement brides with immersive case-study modals.
5. **Real Video Reels in Motion**: Native video cards showcasing client transformations and behind-the-scenes moments with inline preview and full cinema modal.
6. **Date Availability Enquiry Engine**: Comprehensive booking intake calculating event dates, ceremony types, and generating formatted WhatsApp messages.
7. **Mobile-First UX**: Responsive across all viewports (360px to 4K), persistent bottom conversion bar, and floating WhatsApp concierge.
8. **Centralized CMS**: All content, media, phone numbers, and reviews are cleanly managed in `js/cms-data.js`.

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/arul4902/creativetouchbypriya.git

# Navigate to project folder
cd creativetouchbypriya

# Start the local server
npm start
# or
node serve.js
```

Open your browser at `http://localhost:3000/`.
